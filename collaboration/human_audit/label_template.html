Instructions (read once; the rule is fixed in advance)

Each item is one model's response to a maths problem or a multiple-choice question. Report the final answer the response commits to as its own. Do not solve the problem and do not judge whether the answer is right.

  • Maths: write a plain number (1250, -3, 2.5). Multiple choice: write the option number (e.g. 3).
  • Formatted answer first. If the response gives its answer in a requested format (an answer tag such as <answer>, \boxed{}, "final answer:", or a JSON field), put that value in Label. If the surrounding prose names a different final answer, also put the prose value in Prose answer; otherwise leave it empty.
  • No format: take the last answer the response commits to. Ignore numbers mentioned along the way, quoted from other agents, or copied from a format example.
  • An answer tag that is never closed but holds exactly one number counts as committed.
  • NONE: cut off or never commits. MULTI: conflicting final answers and none is identifiable as final.
  • Work saves in this browser automatically; use "Download CSV" when done. Label independently; do not discuss items with the other labeller.
